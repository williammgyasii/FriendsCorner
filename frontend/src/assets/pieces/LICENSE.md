# Chess pieces

The twelve piece drawings in this folder are by Colin M. L. Burnett ("Cburnett"),
from Wikimedia Commons (for example https://commons.wikimedia.org/wiki/File:Chess_nlt45.svg).
The only change is an added `viewBox` so each drawing scales.
